# Static BNAME files

The site publishes exactly four files:

- index.html — original existing page, copied unchanged.
- google1316b7ceb6313ce6.html — supplied Google ownership verification file, copied unchanged.
- bname.html — all 154431 original registry names and their BID values, in one standard HTML document containing a visible ul/li list. No JavaScript, CSS, embedded JSON or pagination.
- bname.txt — the same records as UTF-8 plain text, with a BID/BNAME header, a tab between each BID and name, and one record per line. No HTML or pre tags.

All former glist, bname-N, registry-page-N and channels pages are removed from this publication. There are no legacy redirects, sitemap or robots files generated by this build.

The compressed source data/bname.tsv.gz contains the exact plain text bytes. It is not published as a separate download. The Node 26 build validates its checksum and row count before writing either requested format. The output tests verify every record, order, Unicode spelling, duplicate name, and preserved file byte-for-byte. No name matching or AI checks run during build.
